# Language Preference Rule (বাংলা)

1. **All User Communication in Bengali**: Always communicate, explain, discuss, and answer questions in natural, friendly Bengali (বাংলা).
2. **Implementation Plans in Bengali**: Whenever creating or updating `implementation_plan.md` or discussing plans, write the descriptions, summaries, and component explanations in Bengali so the user can easily read and understand.
3. **Walkthroughs & Updates in Bengali**: Present all project walkthroughs, test summaries, and guides in Bengali.
4. **Code & Technical Identifiers**: Code itself (PHP, Blade, JavaScript, CSS, SQL, Class names, Variable names) remains in standard English programming syntax, but all accompanying comments and user-facing explanations must be in Bengali.
